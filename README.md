# EEI6373_MP
Smart Traffic Light Control System – Performance Modelling (EEI6373)

This repository contains the mini project submission for the EEI6373 – Performance Modelling course offered by the Department of Electrical & Computer Engineering, The Open University of Sri Lanka.

Project Overview

The project evaluates the performance of a Smart Traffic Light Control System, an embedded control system that dynamically adjusts traffic signal timings based on real-time traffic conditions. The study applies performance modelling techniques to analyze system behavior under different traffic loads and identify potential performance bottlenecks.

Objectives
Analyze controller response time under varying traffic volumes.
Evaluate system throughput and vehicle waiting time.
Measure queue length and CPU utilization.
Identify performance bottlenecks.
Assess system scalability under increasing traffic demand.
Propose possible performance improvements.

Dataset

The dataset is simulated for academic purposes based on realistic traffic engineering assumptions. It represents system performance under different traffic volumes and includes the following parameters:

Traffic Volume (vehicles/min)
Controller Response Time (ms)
Average Waiting Time (s)
Queue Length (vehicles)
CPU Utilization (%)
Throughput (vehicles/min)
