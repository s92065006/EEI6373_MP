# EEI6373_MP
# Smart Traffic Light Control System – Performance Modelling

This repository contains the mini project submitted for **EEI6373 – Performance Modelling** at **The Open University of Sri Lanka**.

## Project Overview

The project evaluates the performance of a **Smart Traffic Light Control System**, an embedded control system that dynamically adjusts traffic signal timings based on real-time traffic conditions. The study uses performance modelling techniques to analyze system behavior under different traffic loads and identify performance bottlenecks.

## Objectives

* Minimize controller response time.
* Maximize vehicle throughput.
* Reduce average vehicle waiting time.
* Analyze queue length under different traffic loads.
* Evaluate CPU utilization.
* Assess system scalability.

## Performance Metrics

* Traffic Volume (vehicles/min)
* Controller Response Time (ms)
* Average Waiting Time (s)
* Queue Length (vehicles)
* CPU Utilization (%)
* Throughput (vehicles/min)

## Modeling Techniques

* Queueing Model
* Simulation-Based Performance Analysis
* Performance Metrics Evaluation
